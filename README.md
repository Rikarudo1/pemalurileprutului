## Număr nou
1. Pune PDF-ul în `pdf/`.
2. În `arhiva.html` copiază un bloc `<div class="issue">…</div>`, schimbă titlul și link-ul.
3. În `index.html`, la „Ultimul număr", schimbă titlul și link-ul.
